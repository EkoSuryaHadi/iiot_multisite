Peringatan Client ID Collision:
Jika Client ID di PC sama persis dengan Client ID gateway fisik (solar-jkt-GNIS_MockupUSR), broker EMQX akan memutuskan salah satunya ("Connection closed by server") setiap kali ada yang mengirim paket.

2. Spesifikasi Standar Template Payload JSON Telemetri

Konfigurasikan template data pada menu Data Report USR-M100 dengan format flat numeric key agar ClickHouse TSDB dan Web Dashboard dapat langsung mengekstrak metrik tanpa parsing kompleks:

A. Template Konfigurasi USR-M100: 
{
  "voltage": %Voltage_PLN%,
  "current": %Current_PLN%,
  "frequency": %Frequency_PLN%,
  "power": %Power_PLN%,
  "energy": %Energy_PLN%
}
*Gunakan token variabel Modbus yang dipetakan pada tabel Modbus USR-M100.
B. Hasil Payload JSON yang Diterima Broker: 
{
  "voltage": 220.4,
  "current": 4.85,
  "frequency": 50.02,
  "power": 1068.9,
  "energy": 145.2
}
*Engine analitik otomatis mencatat timestamp server jika device tidak menyertakan key "ts".
