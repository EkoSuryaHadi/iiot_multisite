Dokumentasi REST API Telemetri (On-Demand Pull)

Layanan Integrasi Data Mandiri Multi-Site IIoT Platform

RESTful API v1
Protokol & Format HTTPS / JSON (REST API)
Otentikasi Header: X-API-Key
Format Response Standar Terstruktur & Raw Timeseries

1. Ringkasan & Cara Kerja

Layanan REST API ini memungkinkan tim teknis/developer Anda untuk menarik (pull) data operasional, metrik kelistrikan, performa energi, hingga data telemetri mentah kapan saja secara on-demand untuk dihubungkan ke sistem internal, database lokal, atau visualizer (Grafana, Power BI, Web Portal).

Kredensial Akses: Setiap request wajib menyertakan header X-API-Key: [API_KEY_ANDA]. Base URL produksi adalah: https://[DOMAIN_ATAU_IP_SERVER_KAMI]

2. Endpoint API Tersedia

A. Data Telemetri Mentah Timeseries (Raw Telemetry)

GET /api/v1/external/sites/{site_slug}/telemetry/raw

Digunakan untuk menarik riwayat angka sensor mentah per perangkat dalam rentang waktu tertentu.

Query Parameter Tipe Wajib? Keterangan & Contoh
device_key String Ya Identifier / Key perangkat (contoh: gw-sps-01)
metric_name String Tidak Filter metrik spesifik (contoh: v_pv, p_load, temp). Jika dikosongkan akan mengambil semua metrik.
start / end ISO-8601 Tidak Rentang waktu UTC (contoh: 2026-11-10T00:00:00Z). Default: 1 jam terakhir.
limit Integer Tidak Maksimal baris data (Default: 500, Maks: 2000).
# Contoh Request cURL: curl -X GET "https://[DOMAIN_KAMI]/api/v1/external/sites/site-jkt-01/telemetry/raw?device_key=gw-sps-01&metric_name=v_pv&limit=100" \ -H "X-API-Key: [API_KEY_ANDA]" # Contoh Response JSON: { "site_slug": "site-jkt-01", "device_key": "gw-sps-01", "total": 2, "data": [ { "ts": "2026-11-10T07:00:00.000Z", "metric_name": "v_pv", "metric_value": 54.2 }, { "ts": "2026-11-10T06:59:58.000Z", "metric_name": "v_pv", "metric_value": 54.1 } ] }

B. Snapshot Kelistrikan Real-Time & Efisiensi Energi

GET /api/v1/external/sites/{site_slug}/metrics

Menghasilkan status terkini daya PV, MPPT, Rectifier, Load, Solar Contribution Ratio (SCR), dan Performance Ratio (PR).

curl -X GET "https://[DOMAIN_KAMI]/api/v1/external/sites/site-jkt-01/metrics" \ -H "X-API-Key: [API_KEY_ANDA]"

C. Indeks Kesehatan PV & MPPT Controller

GET /api/v1/external/sites/{site_slug}/health

Menyajikan skor kesehatan PV Array, MPPT Controller, load sharing voltage delta, dan alarm status (HEALTHY, WARNING, CRITICAL).

D. Riwayat Energi Harian & Rekonsiliasi (Daily Aggregation)

GET /api/v1/external/sites/{site_slug}/daily?start_date=2026-11-01&end_date=2026-11-10

Menyajikan total akumulasi harian Solar kWh, Grid Rectifier kWh, Load kWh, dan persentase SCR.

3. Contoh Script Python Penarik Data ke Database Lokal

import requests import pymysql API_KEY = "masukkan-api-key-anda" BASE_URL = "https://[DOMAIN_KAMI]/api/v1/external/sites/site-jkt-01/telemetry/raw" headers = {"X-API-Key": API_KEY} params = {"device_key": "gw-sps-01", "limit": 500} resp = requests.get(BASE_URL, headers=headers, params=params) if resp.status_code == 200: records = resp.json().get("data", []) print(f"Berhasil menarik {len(records)} data telemetri.") # Anda dapat langsung INSERT baris 'records' ini ke database lokal/MySQL Anda
